# 脚本目录说明

`scripts/` 存放本地维护脚本与辅助启动脚本，不放核心业务模块。

## 当前脚本

- `start.sh`
  - 本地开发环境一键启动。
- `reinit_db.py`
  - 重建数据库表结构的维护脚本。
- `task_media_v2_migration.py`
  - 默认执行只读 V1 媒体清点；只有显式 `migrate --account-id ...` 才按账号串行迁移一批任务。

## 维护约定

1. 新脚本优先放在这里，不再把辅助 `.py` 或 `.sh` 直接堆在根目录。
2. 影响生产环境的脚本优先放在 `deploy/`，本目录更偏本地开发和手工维护用途。
