# Bot 文案一致性回归清单

## 核心检查问题

- 我现在处于什么状态？
- 我下一步该点什么？
- 如果失败，我该怎么恢复？

## 核心路径

1. `/start` 未注册
   - 显示 Bot 是主入口
   - 按钮为 `自动注册`、`手动注册`
   - 文案包含“下一步”

2. 自动注册成功
   - 显示用户名与一次性密码
   - 明确下一步去 `激活套餐`
   - 按钮为 `激活套餐`、`查看订阅`

3. 手动注册成功
   - 明确下一步去 `激活套餐`
   - 按钮为 `激活套餐`、`查看订阅`

4. 未激活状态点击受限操作
   - 提示原因
   - 给出 `查看订阅`、`立即购买`
   - 可返回主菜单

5. 激活成功
   - 展示剩余天数、到期时间
   - 明确下一步去 `登录账号`
   - 按钮为 `登录账号`、`查看订阅`

6. 点击购买
   - 展示套餐摘要
   - 明确购买后回 Bot 激活
   - 外链按钮文案统一为 `立即购买`

7. 登录账号
   - 展示二维码
   - 明确扫码后等待数秒
   - 提供 `取消登录`

8. 二步密码输入
   - 说明密码消息会被删除
   - 明确输入后自动绑定
   - 错误时提示重新输入或重新登录

9. 登录成功
   - 展示账号名、Telegram UID、订阅剩余天数
   - 明确下一步去 `查看账号`、`查看任务` 或 `查看绑定码`
   - 按钮符合命名规范

10. 查看绑定码
    - 页面说明绑定码用途
    - 每个账号显示：显示名、绑定码、过期时间、手动命令
    - 支持刷新绑定码和返回主菜单

11. 查看账号
    - 账号列表标题统一
    - 账号详情字段顺序固定
    - 按钮顺序固定：设为当前账号、同步资源、重新登录、查看绑定码、新建任务、解绑账号

12. 查看任务
    - 任务列表标题统一
    - 空态提示明确下一步去 `新建任务`
    - 设置页底部返回路径清晰

## 统一规则

- 按钮命名使用动作优先
- 每个按钮和标题最多一个 emoji
- 同一动作全 Bot 只使用一个叫法
- 失败提示不暴露底层异常
- 成功提示必须包含“下一步”
