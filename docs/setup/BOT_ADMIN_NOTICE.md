# Bot 公告栏管理员说明

本文档仅面向管理员，用于配置 TG Bot 的公告栏与置顶说明。

## 1. 配置入口

进入管理后台：

- `卡密与授权`
- `配置中心`
- `Bot 公告栏配置`

## 2. 可配置字段

- `是否启用`：控制 Bot 首页和帮助页是否展示公告入口
- `Bot 入口按钮文案`：用户在 Bot 中看到的公告入口名称
- `公告正文`：实际展示给用户的公告内容
- `跳转链接`：Telegram 会基于该链接生成原生预览卡片缩略图

## 3. 用户可见位置

保存后，用户可在以下位置看到公告：

- Bot 首页和帮助页的公告入口
- 直接发送 `/notice`
- 已收到公告的聊天消息中，用户可将公告消息手动置顶

系统会尽量在管理员保存后，立即刷新所有已绑定用户聊天里的那条公告消息。

## 4. 推荐公告内容

建议优先写用户最常问的问题：

- 新用户先做什么
- 如何绑定账号
- 如何激活卡密
- 如何创建任务
- 常见报错怎么处理
- 购买入口或联系管理员方式

建议正文按短段落编写，方便手机端阅读。

## 5. 推荐模板

```text
欢迎使用全球通

1. 新用户先点击“绑定账号”
2. 绑定完成后再创建任务
3. 没有授权时请先激活卡密
4. 如提示重新绑定，请按引导重新登录
5. 如需购买卡密，请点击购买入口或联系管理员

常用命令：
/start
/help
/notice
/login
/newtask
```

推荐搭配一个可公开访问的链接，让 Telegram 自动生成预览卡片。

## 6. 排查建议

- 用户看不到公告栏：先检查 `是否启用`
- 公告按钮有但点开为空：检查 `公告正文` 和 `跳转链接` 是否都已填写
- 用户不会操作：让用户先看置顶公告，再点 `📖 帮助` 或发送 `/help`
