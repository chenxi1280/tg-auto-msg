# TG Bot 用户操作手册

本文档仅面向 TG Bot 使用用户。

## 1. 如何开始使用 Bot

### 第一步：进入 Bot

用户在 Telegram 中打开 Bot 后，发送 `/start`。

Bot 首页会根据用户当前状态展示不同入口，常见按钮包括：

- `📢 公告栏`：查看管理员发布的最新公告、活动和使用说明
- `📱 绑定账号`：绑定自己的 Telegram 账号
- `🎟️ 激活卡密`：输入卡密续费当前授权
- `👥 查看账号`：查看已绑定账号
- `🗂️ 查看任务`：查看和管理定时任务

如果用户不知道下一步做什么，优先让他先看：

- `📢 公告栏`
- `📖 帮助`

也可以直接发送命令：

- `/start`
- `/help`
- `/notice`
- `/login`
- `/newtask`

## 2. 标准使用流程

建议按下面顺序操作：

1. 发送 `/start`
2. 点击 `📢 公告栏` 查看最新说明
3. 点击 `📱 绑定账号`，按提示输入手机号、验证码和二步密码
4. 首次成功绑定后，系统会自动赠送 `7 天试用`
5. 如果试用已到期或没有有效授权，点击 `🎟️ 激活卡密`
6. 绑定完成后，点击 `⏰ 创建定时任务`、`🖱️ 创建手动任务` 或 `/newtask`
7. 后续通过 `👥 查看账号`、`🗂️ 查看任务` 继续管理

## 3. 详细操作手册

这份内容建议同时放进公告栏，用户可在置顶公告、`📖 帮助` 和 `/help` 中查看到统一说明。

### 第一步：先看公告或帮助

- 发送 `/start`
- 查看置顶公告
- 点击 `📖 帮助` 或发送 `/help`

### 第二步：绑定自己的 Telegram 账号

- 点击 `📱 绑定账号`
- 按提示输入手机号
- 收到验证码后继续输入
- 如果开启了 Telegram 二步验证，再输入二步密码
- 绑定成功后，系统会自动同步账号资料和可发送目标

如果提示 `系统已更新，请先重新绑定`，说明旧登录状态已经失效，按引导确认解绑后重新绑定即可。

### 第三步：开通或续费授权

- 首次成功绑定 TG 账号后，系统会自动赠送 `7 天试用授权`
- 没有有效授权时，点击 `🎟️ 激活卡密`
- 已有购买渠道时，可点击 `🛒 立即购买`
- 需要确认当前状态时，可点击 `🧾 查看授权`
- 试用结束后，如需继续使用，请输入卡密续费当前唯一授权

### 第四步：任务分哪两种

- `⏰ 定时任务`：按设定时间和间隔自动发送
- `🖱️ 手动任务`：适合做快捷发送，配置好后可放到 Bot 底部快捷栏
- 发送 `/newtask` 时，可先选择要创建哪一种任务

### 第五步：手动任务适合哪些场景

- 常用频道、常用群聊的快捷发送
- 老师或班主任常用的 `一键上课`、`一键下课`
- 社群运营常用的 `一键开播`、`一键收播`
- 客服或通知类场景的固定话术快捷发送
- 手动任务创建后，会显示在 Bot 底部快捷栏中，点击即可立即发送

### 第六步：创建任务

- 点击 `⏰ 创建定时任务`、`🖱️ 创建手动任务` 或发送 `/newtask`
- 选择执行账号
- 选择目标群组、频道或聊天
- 设置发送内容、按钮、发送间隔和时间范围
- 根据需要开启 `置顶`、`删除上一条`
- 保存后到 `🗂️ 查看任务` 中继续管理

### 第七步：任务支持什么发送

- 纯文本消息
- 图片、视频、动图、贴纸
- 带跳转链接的按钮消息
- 文本 + 媒体 + 按钮组合发送
- 支持重复间隔、开始时间、结束时间、每日发送时段
- 支持 `删除上一条` 和 `发送后置顶`
- 链接按钮最多支持 `3 行`，每行最多 `3 个按钮`

### 第八步：什么是自动抖动

- 系统会为任务自动加入随机发送抖动
- 目的是避免消息每次都在完全相同的秒级时间发出
- 这是系统自动控制的防风控策略，用户不需要手动设置
- 所以设置“每 60 分钟”后，实际执行时间可能会有少量随机偏移

### 第九步：卡密如何购买和激活

- 点击 `🛒 立即购买` 可打开管理员配置的购买入口
- 购买完成后，回到 Bot 点击 `🎟️ 激活卡密`
- 输入卡密后，会为当前唯一授权开通或续费
- 如提示卡密无效、已使用或已过期，请联系发卡方确认

### 第十步：日常查看和维护

- `👥 查看账号`：查看账号状态、重新绑定、同步资源
- `🗂️ 查看任务`：查看、编辑、启停、删除任务
- `🔑 查看初始密码`：查看 Bot 自动注册生成的 Web 初始密码
- `📢 公告栏`：查看最新活动、公告和操作说明

### 常用命令

- `/start`
- `/help`
- `/notice`
- `/login`
- `/newtask`

## 4. 公告内容建议

建议把用户最常问的问题放进公告栏，例如：

- 先绑定账号，再创建任务
- 试用规则和续费方式
- 卡密购买入口
- 常见报错处理方式
- 客服或联系渠道

建议内容尽量短一些，按段落分开，方便手机端阅读；卡片缩略图由跳转链接本身决定，不是后台单独上传图片。

## 5. 推荐公告模板

可直接参考下面的结构：

```text
欢迎使用全球通

1. 新用户先点击“绑定账号”
2. 首次成功绑定 TG 后自动赠送 7 天试用
3. 试用到期后请使用卡密续费当前授权
4. 支持创建定时任务和手动任务
5. 手动任务可做常用频道、群聊的一键发送，例如一键上课、一键下课
6. 任务支持文本、图片、视频、动图、贴纸和按钮发送
7. 系统会自动加入随机抖动，无需手动设置
8. 如需购买卡密，请点击“立即购买”或联系管理员

常用命令：
/start
/help
/notice
/login
/newtask
```

推荐搭配一个可公开访问的落地页链接，让 Telegram 自动生成预览卡片。

## 6. 排查建议

- 用户看不到公告栏：先检查后台是否启用了 `Bot 公告栏`
- 公告按钮有但点开为空：检查 `公告正文` 和 `跳转链接` 是否都已填写
- 用户不会操作：让用户先发 `/start`，再看 `📢 公告栏` 或 `/help`
