# Bot 使用说明

本文档面向两类角色：

- 普通用户：不知道从哪里开始时，按下面的流程使用 Bot。
- 管理员：需要在后台配置公告栏，让所有用户在 Bot 里都能看到统一说明。

## 1. 用户如何使用 Bot

### 第一步：进入 Bot

用户在 Telegram 中打开 Bot 后，发送 `/start`。

Bot 首页会根据用户当前状态展示不同入口，常见按钮包括：

- `📢 公告栏`：查看管理员发布的最新公告、活动和使用说明
- `📱 绑定账号`：绑定自己的 Telegram 账号
- `🎟️ 激活卡密`：输入卡密续费当前授权
- `👥 查看账号`：查看已绑定账号
- `🗂️ 查看任务`：查看和管理定时任务

如果用户不知道下一步做什么，优先让他先看：

- `📢 公告栏`
- `📖 帮助`

也可以直接发送命令：

- `/start`
- `/help`
- `/notice`
- `/login`
- `/newtask`

## 2. 标准使用流程

建议按下面顺序操作：

1. 发送 `/start`
2. 点击 `📢 公告栏` 查看最新说明
3. 点击 `📱 绑定账号`，按提示输入手机号、验证码和二步密码
4. 如果没有有效授权，点击 `🎟️ 激活卡密`
5. 绑定完成后，点击 `📝 创建任务` 或 `/newtask`
6. 后续通过 `👥 查看账号`、`🗂️ 查看任务` 继续管理

## 3. 管理员如何配置公告栏

进入管理后台：

- `卡密与授权`
- `配置中心`
- `Bot 公告栏配置`

可配置字段：

- `是否启用`：控制 Bot 首页和帮助页是否展示公告入口
- `Bot 入口按钮文案`：用户在 Bot 中看到的公告入口名称
- `公告正文`：实际展示给用户的公告内容
- `跳转链接`：Telegram 会基于该链接生成原生预览卡片缩略图

保存后，用户可在以下位置看到：

- Bot 首页和帮助页的公告入口
- 直接发送 `/notice`
- admin 保存后，系统会尽量立即刷新所有已绑定用户聊天里的那条公告消息

## 4. 公告内容建议

建议把用户最常问的问题放进公告栏，例如：

- 先绑定账号，再创建任务
- 试用规则和续费方式
- 卡密购买入口
- 常见报错处理方式
- 客服或联系渠道

建议内容尽量短一些，按段落分开，方便手机端阅读；卡片缩略图由跳转链接本身决定，不是后台单独上传图片。

## 5. 推荐公告模板

可直接参考下面的结构：

```text
欢迎使用全球通

1. 新用户先点击“绑定账号”
2. 首次绑定成功后可获得试用资格
3. 试用到期后请使用卡密续费
4. 创建任务前，请先确认账号状态正常
5. 如需购买卡密，请点击“立即购买”或联系管理员

常用命令：
/start
/help
/notice
/login
/newtask
```

推荐搭配一个可公开访问的落地页链接，让 Telegram 自动生成预览卡片。

## 6. 排查建议

- 用户看不到公告栏：先检查后台是否启用了 `Bot 公告栏`
- 公告按钮有但点开为空：检查 `公告正文` 和 `跳转链接` 是否都已填写
- 用户不会操作：让用户先发 `/start`，再看 `📢 公告栏` 或 `/help`
