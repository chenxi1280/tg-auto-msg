# TG Bot 用户操作手册

本文档仅面向 TG Bot 使用用户。

## 1. 如何开始使用 Bot

### 第一步：进入 Bot

用户在 Telegram 中打开 Bot 后，发送 `/start`。

Bot 首页会根据用户当前状态展示不同入口，常见按钮包括：

- `📢 公告栏`：查看管理员发布的最新公告、活动和使用说明
- `📱 绑定账号`：绑定自己的 Telegram 账号
- `🎟️ 激活卡密`：输入卡密续费当前授权
- `👥 查看账号`：查看已绑定账号
- `🗂️ 查看任务`：查看和管理定时任务

如果用户不知道下一步做什么，优先让他先看：

- `📢 公告栏`
- `📖 帮助`

也可以直接发送命令：

- `/start`
- `/help`
- `/notice`
- `/login`
- `/newtask`

## 2. 标准使用流程

建议按下面顺序操作：

1. 发送 `/start`
2. 点击 `📢 公告栏` 查看最新说明
3. 点击 `📱 绑定账号`，按提示输入手机号、验证码和二步密码
4. 如果没有有效授权，点击 `🎟️ 激活卡密`
5. 绑定完成后，点击 `📝 创建任务` 或 `/newtask`
6. 后续通过 `👥 查看账号`、`🗂️ 查看任务` 继续管理

## 3. TG Bot 用户操作手册

这份内容建议同时放进公告栏，用户可在置顶公告、`📖 帮助` 和 `/help` 中查看到统一说明。

### 第一步：先看公告或帮助

- 发送 `/start`
- 查看置顶公告
- 点击 `📖 帮助` 或发送 `/help`

### 第二步：绑定自己的 Telegram 账号

- 点击 `📱 绑定账号`
- 按提示输入手机号
- 收到验证码后继续输入
- 如果开启了 Telegram 二步验证，再输入二步密码

如果提示 `系统已更新，请先重新绑定`，说明旧登录状态已经失效，按引导确认解绑后重新绑定即可。

### 第三步：开通或续费授权

- 没有有效授权时，点击 `🎟️ 激活卡密`
- 已有购买渠道时，可点击 `🛒 立即购买`
- 需要确认当前状态时，可点击 `🧾 查看授权`

### 第四步：创建定时任务

- 点击 `📝 创建任务` 或发送 `/newtask`
- 选择执行账号
- 选择目标群组、频道或聊天
- 设置发送内容、按钮、发送间隔和时间范围
- 根据需要开启 `置顶`、`删除上一条`
- 保存后到 `🗂️ 查看任务` 中继续管理

### 第五步：日常查看和维护

- `👥 查看账号`：查看账号状态、重新绑定、同步资源
- `🗂️ 查看任务`：查看、编辑、启停、删除任务
- `📢 公告栏`：查看最新活动、公告和操作说明

### 常用命令

- `/start`
- `/help`
- `/notice`
- `/login`
- `/newtask`

## 4. 公告内容建议

建议把用户最常问的问题放进公告栏，例如：

- 先绑定账号，再创建任务
- 试用规则和续费方式
- 卡密购买入口
- 常见报错处理方式
- 客服或联系渠道

建议内容尽量短一些，按段落分开，方便手机端阅读；卡片缩略图由跳转链接本身决定，不是后台单独上传图片。

## 5. 推荐公告模板

可直接参考下面的结构：

```text
欢迎使用全球通

1. 新用户先点击“绑定账号”
2. 首次绑定成功后可获得试用资格
3. 试用到期后请使用卡密续费
4. 创建任务前，请先确认账号状态正常
5. 如需购买卡密，请点击“立即购买”或联系管理员

常用命令：
/start
/help
/notice
/login
/newtask
```

推荐搭配一个可公开访问的落地页链接，让 Telegram 自动生成预览卡片。

## 6. 排查建议

- 用户看不到公告栏：先检查后台是否启用了 `Bot 公告栏`
- 公告按钮有但点开为空：检查 `公告正文` 和 `跳转链接` 是否都已填写
- 用户不会操作：让用户先发 `/start`，再看 `📢 公告栏` 或 `/help`
